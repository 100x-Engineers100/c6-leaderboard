--------------------------------------------------------------------------------
DATABASE SCHEMA (Leaderboard Supabase)
--------------------------------------------------------------------------------

  students
  --------
  id              UUID PRIMARY KEY DEFAULT gen_random_uuid()
  name            VARCHAR NOT NULL
  email           VARCHAR UNIQUE NOT NULL
  avatar_url      VARCHAR                    -- Tally pre-signed URL
  edmingle_id     VARCHAR                    -- populated on first attendance sync
  ugc_user_id     VARCHAR                    -- matched from UGC tracker by email
  cohort          VARCHAR DEFAULT 'C7'
  created_at      TIMESTAMP DEFAULT now()

  student_points
  --------------
  id                    UUID PRIMARY KEY DEFAULT gen_random_uuid()
  student_id            UUID REFERENCES students(id) UNIQUE NOT NULL
  attendance_pts        INT DEFAULT 0
  ugc_post_pts          INT DEFAULT 0
  consistency_bonus_pts INT DEFAULT 0
  assignment_pts        INT DEFAULT 0        -- manual entry
  hackathon_pts         INT DEFAULT 0        -- manual entry
  capstone_pts          INT DEFAULT 0        -- manual entry
  total_points          INT GENERATED ALWAYS AS (
                          attendance_pts + ugc_post_pts + consistency_bonus_pts +
                          assignment_pts + hackathon_pts + capstone_pts
                        ) STORED
  last_synced_at        TIMESTAMP
  updated_at            TIMESTAMP DEFAULT now()

  attendance_records
  ------------------
  id                  UUID PRIMARY KEY DEFAULT gen_random_uuid()
  student_id          UUID REFERENCES students(id)
  edmingle_student_id VARCHAR
  session_date        DATE NOT NULL
  session_name        VARCHAR
  is_present          BOOLEAN NOT NULL
  created_at          TIMESTAMP DEFAULT now()
  UNIQUE (student_id, session_date)          -- dedup key

  ugc_posts_cache
  ---------------
  id           UUID PRIMARY KEY DEFAULT gen_random_uuid()
  student_id   UUID REFERENCES students(id)
  post_url     VARCHAR UNIQUE NOT NULL       -- dedup key
  num_likes    INT DEFAULT 0
  num_comments INT DEFAULT 0
  posted_at    TIMESTAMP
  platform     VARCHAR DEFAULT 'LINKEDIN'
  synced_at    TIMESTAMP DEFAULT now()

COMMON PITFALLS (ENCOUNTERED AND FIXED)
--------------------------------------------------------------------------------

  1. COHORT ID TYPO
     Plan had wrong C7 cohort ID: 4c8458b3-a700-42b2-9cb1-f52b3045e2c3
     Actual ID in UGC DB:         4c8458b3-a700-42b2-9cc1-f52b3045e2c3
     Difference: 9cb1 vs 9cc1 (one character)
     Impact: UGC sync returned 0 users
     Fix: corrected in sync-ugc.mjs and seed-students.mjs

  2. UGC SUPABASE PERMISSION DENIED
     Error: "permission denied for schema public"
     Cause: Newer Supabase projects revoke default PostgREST schema grants.
            Even with service_role key, USAGE on public schema must be
            explicitly granted.
     Fix: Run in UGC Tracker SQL Editor:
       GRANT USAGE ON SCHEMA public TO anon, authenticated, service_role;
       GRANT SELECT ON ALL TABLES IN SCHEMA public TO anon, authenticated, service_role;
       GRANT SELECT ON ALL SEQUENCES IN SCHEMA public TO anon, authenticated, service_role;

  3. DOTENV LOADING .env vs .env.local
     dotenv/config defaults to .env, not .env.local.
     Fix: scripts use config({ path: join(process.cwd(), '.env.local') })

  4. SUPABASE CLIENT THROWS AT BUILD TIME
     lib/supabase.ts initially threw if env vars were missing at module load.
     Next.js build executes module-level code, causing build failure.
     Fix: lazy singleton — only throws at request time inside getSupabase()

  5. GSAP NULL REF ERROR ON LOAD
     usePodiumAnimation ran immediately on mount. PodiumTVs returned early
     (empty div) while data loaded, so tv1/2/3Ref were null.
     Error: TypeError: Cannot read properties of null (reading '_gsap')
     Fix: usePodiumAnimation(ready: boolean) — effect skips if !ready.
          PodiumTVs passes ready = !!(s1 && s2 && s3). Animation fires
          once real top-3 data arrives.

  6. CSV ROW COUNT MISMATCH
     Simple line-count gave 326 rows. Correct CSV parser gave 134 rows.
     Cause: quoted fields contain embedded newlines — line-split is wrong.
     Fix: proper CSV parser that respects quoted fields.

  7. DUPLICATE EMAILS IN ROSTER CSV
     5 students submitted the Launchpad form twice.
     Fix: seed script deduplicates by email, first-occurrence wins.

  8. STUDENT COUNT MUCH LOWER THAN EXPECTED
     Plan estimated ~327 students. Actual: 129 unique students.
     Cause: the plan was based on a rough estimate, not the actual CSV.
